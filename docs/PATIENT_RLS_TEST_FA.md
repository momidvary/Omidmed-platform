# تست دسترسی‌های ماژول بیمار

فایل: `database/tests/patient_clinical_rls_tests.sql`

1. شش کاربر تست در Authentication → Users بسازید.
2. UUID ها را ابتدای فایل جای‌گذاری کنید.
3. کل فایل را در SQL Editor اجرا و پنل Logs را ببینید — این سناریوها
   باید PASS شوند:
   - جداسازی دو کلینیک (بیمار/جلسه/اندازه‌گیری کلینیک دیگر دیده نشود)
   - منشی: ویرایش اداری ✅، نوشتن جلسه/اندازه‌گیری/ارزیابی ❌
   - فیزیوتراپیست تخصیص‌یافته ✅ / تخصیص‌نیافته ❌
   - بیمار: جدول خام sessions ❌، ویو خلاصه‌های خودش ✅، اندازه‌گیری
     غیرقابل‌مشاهده ❌، قابل‌مشاهده ✅، نوشتن ❌، ارزیابی ❌
   - ثبت‌شدن ردیف‌های Audit
4. در پایان داده تست خودکار پاک می‌شود.

خطای رایج: اگر PASS 4b نگرفتید، مطمئن شوید migration 013 اجرا شده
(ویو patient_session_summaries را همان می‌سازد).
