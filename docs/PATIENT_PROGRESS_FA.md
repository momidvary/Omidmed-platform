# داشبورد پیشرفت

مسیر: صفحه دوره → «پیشرفت».

## چه چیزی می‌بینید
- کارت‌های جلسات: برنامه‌ریزی‌شده، انجام‌شده، باقی‌مانده، فراتر از برنامه
- برای هر معیار: خط پایه (اولین)، آخرین مقدار، هدف (یا «بدون هدف»)،
  تغییر مطلق، تعداد اندازه‌گیری، و نمودار روند (SVG بدون کتابخانه
  خارجی — Responsive و قابل Print)
- فیلترها: معیار، بازه تاریخ

## قواعد نمایش (که برنامه رعایت می‌کند)
- با یک اندازه‌گیری نمودار کشیده نمی‌شود.
- خط پایه صفر → درصد تغییر محاسبه نمی‌شود.
- برچسب «بهبود/بدتر» فقط برای معیارهای higher/lower؛ معیارهای خنثی یا
  تفسیری برچسب خودکار نمی‌گیرند.
- واحدهای متفاوت مقایسه نمی‌شوند (هشدار می‌گیرید).
- معیار Categorical درصد پیشرفت ندارد.
