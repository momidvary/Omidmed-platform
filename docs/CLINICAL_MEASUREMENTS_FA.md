# اندازه‌گیری‌های بالینی

مسیر: صفحه دوره → «پیشرفت».

## فعال‌سازی معیارها
اولین بار دکمه «فعال‌سازی معیارهای پیشنهادی این ناحیه» را بزنید تا
معیارهای استاندارد ناحیه دوره (زانو/کمر/شانه/گردن و…) برای کلینیک شما
ساخته شوند. هر معیار: نوع داده، واحد، محدوده مجاز، جهت بهبود
(higher/lower/target/تفسیر درمانگر) و «قابل مشاهده برای بیمار» دارد.

## ثبت اندازه‌گیری
معیار را انتخاب و مقدار را وارد کنید:
- مقدار باید با نوع داده معیار سازگار باشد (دیتابیس هم بررسی می‌کند).
- مقدار خارج از محدوده، هشدار زرد می‌گیرد (ولی ثبت می‌شود).
- هر ثبت/ویرایش/حذف در Audit ثبت می‌شود.

## دسترسی
- بیمار و منشی نمی‌توانند اندازه‌گیری ثبت یا ویرایش کنند.
- بیمار فقط معیارهای patient_visible خودش را می‌خواند.
- اندازه‌گیری‌های دوره‌های مختلف هرگز مخلوط نمی‌شوند.
